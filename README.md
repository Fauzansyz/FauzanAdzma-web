# 🌐 Zandeveloper ( Web )

A personal portfolio website that documents my journey as a developer.  
Built with simplicity, clarity, and continuous improvement in mind.

> Not perfect. Still growing. That’s the point.

---

## ✨ Highlights

- 📱 Fully responsive (mobile-first, desktop-friendly)
- 🌙 Dark / Light mode with smooth animated transition
- 🧭 Journey timeline with subtle motion
- 🧠 Skills section with clear visual grouping
- 🧩 Projects showcase
- 📬 Contact section
- ⚡ Fast build with modern tooling

---

## 🛠 Tech Stack

- **React** — component-based UI
- **Vite** — fast development & build
- **Tailwind CSS** — utility-first styling
- **Framer Motion** — animations & interactions
- **React Icons** — skill & social icons

---

## 📂 Project Structure (Simplified)

```txt
src/
```

## 🚀 Getting Started

clone this repository then run

```txt
npm run dev
```

```txt
npm run build
```
